## Setup Users and Group

```terminal
useradd user1
useradd user2
useradd user5
useradd user7
groupadd groupbit
usermod -aG groupbit user1
usermod -aG groupbit user2
```

---

## /poweracl — ACL-based access control

user5만 접근 허용, user1·user2·user7 명시적 차단.

```terminal
mkdir /poweracl
chmod 770 /poweracl
setfacl -m u:user5:rx /poweracl
setfacl -m u:user1:--- /poweracl
setfacl -m u:user2:--- /poweracl
setfacl -m u:user7:--- /poweracl
```

> `chmod 770` 으로 other 접근을 차단한 후,  
> ACL로 user5에게만 진입(rx) 권한을 부여하고 나머지 세 계정은 명시적으로 차단한다.

```terminal
# 확인
getfacl /poweracl
```

## /groupbit — SetGID (privilege propagation)

groupbit 그룹 멤버(user1, user2)에게 rw 허용, 하위 파일/디렉터리가 그룹을 상속받도록 SetGID 설정.

```terminal
mkdir /groupbit
chown root:groupbit /groupbit
chmod 2770 /groupbit
```

> `2770` = SetGID(2) + rwxrwx--- 구조.  
> SetGID(`g+s`)가 설정되면 /groupbit 안에 생성된 파일·디렉터리는 생성자 기본 그룹이 아닌 **groupbit 그룹을 상속**한다.

```terminal
# 확인
ls -ld /groupbit
# 결과 예시: drwxrws--- ... groupbit /groupbit
```

## /allbit — Sticky Bit

모든 사용자가 쓰기 가능하지만, 파일 삭제는 **소유자 본인만** 허용.

```terminal
mkdir /allbit
chmod 1777 /allbit
```

> `1777` = Sticky Bit(1) + rwxrwxrwx.  
> Sticky Bit(`o+t`)가 설정된 디렉터리에서는 다른 사람이 만든 파일을 삭제할 수 없다 (`/tmp` 동작과 동일).

```terminal
# 확인
ls -ld /allbit
# 결과 예시: drwxrwxrwt ... /allbit
```
